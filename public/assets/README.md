# Assets

Version 1 builds the entire world and characters **procedurally** from basic
Three.js shapes and CSS, so no binary art assets are required to run the game.

Drop future art here as the game grows:

- `models/` — glTF (`.glb`) models for morphs, NPCs and props (Version 4)
- `audio/` — funny sound effects and background music (Version 4)
- `textures/` — candy/grass/water textures
- `sprites/` — 2D art for the simple-mode renderer
- `icons/` — favicon / PWA icons

Everything in `/public` is served from the site root, e.g.
`/assets/audio/roar.mp3`.
